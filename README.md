# whale-ASMR
一个干净的AMSR播放器。目前仅支持B站源/A clean AMSR player. Currently only supports Bilibili sources
我做它的初衷很简单：我的睡眠不好，需要听一点白噪声睡觉。但是每天晚上我打开B站都会忍不住刷视频，直到深夜才打开白噪声。为了规范睡眠时间我做了这个软件
该软件支持视频与直播播放。可以通过链接添加你喜欢的UP主。支持歌单定制，支持定时和后台播放，支持下载。
该软件后续也许会更新，看情况吧，后续可能会更新其他视频源
感谢Deepseek及其harness提供代码支持，感谢千问提供系统性的梳理。提示词也会开源到仓库。可以直接下载APK使用。
