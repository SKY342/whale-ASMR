## 一、项目概述

- 应用名称：鲸鱼助眠
- 目标平台：Android（arm64-v8a）
- 技术栈：React Native 0.74 + Expo SDK 51 + TypeScript + react-native-track-player + zustand + expo-sqlite + expo-file-system + axios
- 功能定位：B站视频/直播的纯音频助眠播放器

## 二、架构设计

- 入口：`App.tsx` → `ThemeProvider` → `SafeAreaProvider` → `PaperProvider` → `GlobalBackground` → `NavigationContainer`
- 页面：底部四 Tab（视频/直播/歌单/我的）+ 栈页面（播放器/搜索/历史/关注/收藏/皮肤/设置等）
- 状态：zustand（播放器、播放队列、搜索、下载、设置、弹窗）
- 数据：expo-sqlite（SQLite 本地库）
- 播放：react-native-track-player（含锁屏控制、后台播放）

## 三、主题系统

- 文件：`src/themes/theme.ts`、`src/themes/ThemeContext.tsx`
- 5 套主题：默认 / 静谧夜蓝 / 暗夜暖灰 / 暮色暖调 / 鲸鱼娘·梦幻深蓝
- 持久化：SQLite `settings` 表，键 `theme_id`
- 背景图：仅鲸鱼娘主题使用 `example_photo/鲸鱼娘.jpg`，透明度 0.6
- 全局接入：`GlobalBackground`、`ThemedDialog`、TabBar 均读取 `useTheme()`

## 四、搜索与屏蔽

- 搜索接口：`/x/web-interface/search/type`（`search_type=video` / `live_room`）
- 当前策略：单页 20 条，不做主搜索分页
- 屏蔽词：读取 `blocked_keywords` 表，过滤标题/作者/描述/标签
- 搜索记录：`search_history` 表，最多 40 条，仅在「我的 → 搜索记录」展示

## 五、历史记录

- 表：`history`，字段 item_id/item_type/title/author/cover_url/duration/play_count/viewed_at
- 去重置顶：`UNIQUE(item_id, item_type)` + `ON CONFLICT DO UPDATE`
- 上限 40 条，自动裁剪
- 写入时机：播放成功后异步写入
- 页面：`HistoryScreen`（全部/视频/直播 Tab + 本地搜索 + 清空）

## 六、我的关注 / 收藏

- 关注：`FollowsScreen`，点击进 UP主作品列表（App 内），显示头像/昵称，可删除
- 关注 URL 规范化：`https://space.bilibili.com/{uid}/upload/video`，读取时自动修复旧数据
- 关注写入容错：`getUpInfo` 失败也先用播放器数据落库
- 收藏：`FavoritesScreen`，支持搜索、删除、App 内播放
- 播放队列来源：推荐/搜索/直播/歌单/UP主作品/收藏/历史

## 七、数据库设计

- 表：blocked_keywords / playlists / playlist_items / downloads / follows / favorites / play_history / cache / settings / history / search_history
- 索引：follows(uid)、history(viewed_at)、history(item_type)、search_history(searched_at)

## 八、B站接口清单

- `x/web-interface/nav`：WBI key
- `x/web-interface/search/type`：视频/直播搜索
- `x/web-interface/view`：视频信息
- `x/player/playurl`：音频流（WBI 签名）
- `x/web-interface/card`：UP主信息
- `x/space/wbi/arc/search`：UP主投稿（易风控，失败走搜索兜底）
- `live.bilibili.com/room/v1/Room/get_info`：直播间 UP主 uid
- `live.bilibili.com/room/v1/Room/playUrl`：直播流

## 九、构建与发布

- 分支：`v0.45-optimize`

- Hermes：开启
